GitHub → Railway connection
1

Create a Railway project. Add a PostgreSQL service — Railway generates DATABASE_URL automatically and injects it into linked services.

2

Add a second service → "Deploy from GitHub repo" → connect your account and select the repository.

3

Set environment variables in Railway dashboard: DISCORD_TOKEN, DISCORD_CLIENT_ID, NODE_ENV=production. The DATABASE_URL is injected automatically from the linked PostgreSQL service.

4

Push to main — Railway detects Node.js via Nixpacks and builds automatically. Every subsequent push to main triggers a redeploy with zero manual steps.

5

DB migrations run automatically on startup via the start command in railway.json. No manual schema steps needed.

Runtime dependencies

discord.js v14

Slash commands, buttons, select menus, embeds. The only Discord library with full interactions API support needed for this bot.

TypeScript 5.x

Strict mode across all modules. Type-safe game data, DB queries, Discord interactions, and JSON assets. Catches bugs before production.

Drizzle ORM

Schema-as-code with auto-generated SQL migrations. Type-safe queries that compile to raw SQL. Significantly lighter footprint than Prisma.

pg (node-postgres) v8

PostgreSQL driver used by Drizzle. Connection pooling via pg.Pool — keeps DB connections from exhausting Railway's limits.

Zod v3

Runtime validation for command inputs and JSON game asset files. Surfaces malformed data as descriptive errors rather than silent crashes.

Pino

Extremely fast structured logger. JSON output compatible with Railway's log search. Negligible memory overhead compared to Winston.

node-cache

In-process TTL cache for zones, enemy definitions, and item catalogs. Eliminates repeat DB queries for static data. Replaces Redis entirely.

node-cron

Cron jobs for daily quest refresh, world boss spawns, and leaderboard snapshots. No separate worker process or queue needed.

Dev tooling

tsx

Runs TypeScript directly without compiling. Used in development with tsx watch src/index.ts for instant hot-reload.

tsup

Bundles TypeScript to a single dist/index.js for production. esbuild-based build completes in under 1 second.

drizzle-kit

Generates and runs SQL migrations from schema changes. npm run migrate runs on every Railway deployment automatically.

Vitest

Unit tests for combat formulas, loot tables, and economy functions. No Discord connection or database required — pure logic tests.

ESLint + Prettier

Consistent code style enforced in CI. GitHub Actions blocks any PR with lint errors or type errors from merging to main.

Core tables

players

id uuid PRIMARY KEY DEFAULT gen_random_uuid() discord_id varchar(20) UNIQUE NOT NULL username varchar(32) NOT NULL level int DEFAULT 1 exp bigint DEFAULT 0 gold bigint DEFAULT 500 gems int DEFAULT 0 prestige int DEFAULT 0 class varchar(20) DEFAULT 'novice' hp_current int NOT NULL created_at timestamptz DEFAULT now() last_seen timestamptz

player_stats

player_id uuid REFERENCES players ON DELETE CASCADE hp_max int NOT NULL mana_max int NOT NULL attack int NOT NULL defense int NOT NULL crit_chance numeric(5,2) DEFAULT 5.00 crit_dmg numeric(5,2) DEFAULT 150.00 speed int DEFAULT 10 luck int DEFAULT 5 PRIMARY KEY (player_id) -- Recomputed on level-up + equipment change

inventory

id uuid PRIMARY KEY DEFAULT gen_random_uuid() player_id uuid REFERENCES players ON DELETE CASCADE item_id varchar(64) NOT NULL -- key into items.json quantity int DEFAULT 1 durability int enhancement int DEFAULT 0 equipped boolean DEFAULT false acquired_at timestamptz DEFAULT now() INDEX (player_id, item_id)

player_equipment

player_id uuid REFERENCES players ON DELETE CASCADE weapon uuid REFERENCES inventory helmet uuid REFERENCES inventory chest uuid REFERENCES inventory gloves uuid REFERENCES inventory boots uuid REFERENCES inventory accessory uuid REFERENCES inventory pet uuid REFERENCES inventory PRIMARY KEY (player_id) -- NULL = slot is empty

cooldowns

player_id uuid REFERENCES players ON DELETE CASCADE action varchar(32) NOT NULL -- e.g. 'explore', 'daily', 'craft', 'repair' expires_at timestamptz NOT NULL PRIMARY KEY (player_id, action) -- No background timers — compare now() vs expires_at on demand

combat_sessions

id uuid PRIMARY KEY DEFAULT gen_random_uuid() player_id uuid UNIQUE REFERENCES players ON DELETE CASCADE enemy_id varchar(64) NOT NULL zone_id varchar(32) NOT NULL state jsonb NOT NULL -- { player_hp, player_mana, enemy_hp, round, buffs[] } message_id varchar(20) -- Discord message to edit each turn expires_at timestamptz NOT NULL -- Abandoned sessions expire automatically in 10 min

player_quests

id uuid PRIMARY KEY DEFAULT gen_random_uuid() player_id uuid REFERENCES players ON DELETE CASCADE quest_id varchar(64) NOT NULL -- key into quests.json progress jsonb DEFAULT '{}' -- { "kills": 3, "required": 10 } started_at timestamptz DEFAULT now() completed_at timestamptz INDEX (player_id, quest_id)

guilds + guild_members

-- guilds id uuid PRIMARY KEY DEFAULT gen_random_uuid() name varchar(32) UNIQUE NOT NULL level int DEFAULT 1 exp bigint DEFAULT 0 treasury bigint DEFAULT 0 leader_id uuid REFERENCES players -- guild_members guild_id uuid REFERENCES guilds ON DELETE CASCADE player_id uuid REFERENCES players ON DELETE CASCADE rank varchar(16) DEFAULT 'member' joined_at timestamptz DEFAULT now() PRIMARY KEY (guild_id, player_id)

transactions

id uuid PRIMARY KEY DEFAULT gen_random_uuid() player_id uuid REFERENCES players ON DELETE CASCADE type varchar(32) NOT NULL -- 'quest_reward' | 'combat_loot' | 'shop_purchase' | 'repair' amount bigint NOT NULL -- positive = gain, negative = spend currency varchar(8) DEFAULT 'gold' description text created_at timestamptz DEFAULT now() INDEX (player_id, created_at DESC)

world_bosses + participants

-- world_bosses id uuid PRIMARY KEY DEFAULT gen_random_uuid() boss_id varchar(64) NOT NULL -- key into enemies.json hp_current bigint NOT NULL hp_max bigint NOT NULL spawned_at timestamptz DEFAULT now() defeated_at timestamptz channel_id varchar(20) message_id varchar(20) -- the boss embed, edited each hit -- boss_participants boss_id uuid REFERENCES world_bosses ON DELETE CASCADE player_id uuid REFERENCES players ON DELETE CASCADE damage_dealt bigint DEFAULT 0 PRIMARY KEY (boss_id, player_id)
Key indexes
players.discord_id UNIQUE — looked up on every Discord interaction
inventory.(player_id, item_id) Composite — bag display and stack-count checks
cooldowns.(player_id, action) Primary key — checked before every game action
combat_sessions.player_id UNIQUE — enforces one active combat per player
transactions.(player_id, created_at DESC) Composite — time-range queries for economy audit
players.(level DESC, exp DESC) Composite — leaderboard ORDER BY without full scan
Core systems — build first Core

Player accounts & progression

Core

Discord-linked profiles. Level 1–20 prototype range. 8 primary stats. Prestige resets with multiplier bonuses. Class selection unlocked at level 5.

Turn-based combat

Core

Discord button UI per turn: Attack, Defend, Skill, Use Item, Flee. State stored in DB with 10-minute expiry. Crits, dodge, buffs, debuffs, status effects.

Exploration & zones

Core

5 zones gated by level. Weighted encounter table: normal mob (55%), rare (15%), boss (5%), treasure (10%), empty (15%). Per-player zone cooldowns.

Inventory & equipment

Core

7 equipment slots. Rarity: Common → Mythic. Enhancement +1–+10 with escalating failure chance. Durability drain and repair costs as a gold sink.

Quest engine

Core

JSON-defined conditions (kill N enemies, reach level X, gather Y). Progress in JSONB. Daily refresh, weekly cycle, and permanent story quest chains.

Dual-currency economy

Core

Gold (earnable) + Gems (premium/earned). NPC shop, repair fees, enhancement costs, guild dues as sinks. Full transaction ledger for every movement.

Achievements

Core

Milestone events fired from all game systems. JSON-defined unlock conditions. Rewards: currency, titles, cosmetics, exclusive gear. Progress tracked per player.

Leaderboards

Core

Level, gold, kills, quests, guild power. Paginated embeds. Indexed DB sort. Snapshot refreshed every 15 minutes by cron. Optional weekly reset.

Extended systems — build second Extended

Guilds

Extended

Create, join, leave, kick. Member ranks (leader, officer, member). Guild level + shared XP pool. Treasury. Guild-exclusive quests and leaderboard category.

Crafting

Extended

Materials from exploration drops. JSON recipe definitions. Success rate scales with crafting skill. Multi-tier quality rolls: normal, quality, perfect.

Pets

Extended

4 rarities (Common → Legendary). Passive stat bonuses and active abilities. Pet XP earned via battles. Pet fusion for evolution planned as a future upgrade.

Daily systems

Extended

Login reward with 7-day streak multiplier. Daily quest pool refresh at UTC midnight via cron. Weekly leaderboard snapshot + cycle reset.

World bosses

Extended

Cron-spawned in a dedicated channel. Community HP pool scales with server size. Damage per player tracked. Top-damage bonus rewards on defeat.

Character classes

Extended

Choose at level 5: Warrior, Mage, Rogue, Ranger, Healer. Each modifies base stats and unlocks class-specific skills. Class reroll costs premium currency.

Skill trees

Extended

Skill points every 2 levels. Active combat skills and class passives. Ultimate skills at level 15+. Full skill reset available via gems.

Gacha / summon banner

Extended

Gem-funded summon system. Pity counter at 90 pulls guarantees high rarity. Separate cosmetics banner to avoid pay-to-win pressure on gear.

Future systems — long-term roadmap Future

Dungeon system

Procedurally generated multi-room runs. Room types: combat, trap, treasure, puzzle, boss. Run state persisted in DB. Daily and weekly rotating variants.

PvP arena

Async player-vs-player with MMR ranking. 24-hour challenge window. Seasonal leaderboard with exclusive PvP-only gear as rewards.

Party system

Future

Form parties up to 5 players. Group exploration with shared need/greed loot rolls. Party combat vs elite enemies and multi-phase raid bosses.

Auction house

Player-to-player marketplace. 5% listing fee as a gold sink. Buyout and auction bid modes. 48-hour listings with auto-expiry and item return.

World events

Future

Server-wide cooperative goals. Invasion waves, resource collection milestones, community rewards when thresholds are met. Limited-time event items.

Seasonal content

Future

Time-gated holiday events with exclusive cosmetics and achievements. DB timestamp activation — no code changes needed to start or end a season.

Mounts

Future

Cosmetic + exploration cooldown reduction. Craftable, droppable, and event-exclusive variants. Separate mount slot added to the equipment system.

Fishing minigame

Future

Button timing-based catch mechanic in a dedicated zone. Unique fish used in crafting recipes. Fishing level with rare legendary fish encounters.
